AI processing pipeline — request to structured output

1
Input ingestion
Accept raw text paste OR file upload (PDF/DOCX). File parser extracts clean text via pdf-parse / mammoth. Sanitise and truncate to LLM context limit.
Node.js S3 pre-signed URL for uploads
2
Prompt construction
System prompt (your elite consultant persona) + user brief injected into {"{"}"{"}"} placeholder. JSON-only output enforced via system instructions. Temperature low (0.2–0.4) for structured fidelity.
Prompt template engine Token counter guard
3
Streaming LLM call
Server-Sent Events (SSE) pipe: Node.js streams LLM delta chunks → API Gateway → React client. Frontend accumulates raw JSON string character-by-character and progressively reveals sections as JSON keys become parseable.
SSE / EventSource Partial JSON streaming parser
4
JSON validation + repair
On stream completion, validate full JSON against your schema. If malformed (LLMs occasionally cut off), run a repair pass or re-request the broken section only. Assign a schema-level confidence score per field.
Zod schema validation Fallback re-prompt
5
Proposal persistence + version
Validated JSON stored to S3 with version suffix (userId/proposalId/v1.json). Metadata (timestamps, model used, input hash) saved to DynamoDB or MongoDB document. Enables revision history diff.
S3 versioned bucket Revision history index

Streaming display pattern
Use a partial JSON streamer: as chunks arrive, attempt JSON.parse(buffer) every 200ms. Once a top-level key like "project_summary" is complete, render its card immediately — don't wait for the full response. Use Skeleton loaders for sections still streaming.

⚠ Critical Lambda constraint
Lambda has a 29-second API Gateway timeout. LLM streaming calls often exceed this. Use ECS Fargate for the generation endpoint, or switch to WebSocket API + Lambda for chunked streaming. Plan this early — it affects your infra cost model.

The confidence grid — your signature UI feature

This is what makes the output feel premium. Each feature/risk card has a colour-coded left accent, a confidence score bar, and a complexity/impact badge — all derived directly from the LLM JSON. Below is a live preview of how it renders.
How to implement the confidence grid
1. LLM JSON already returns "confidence": "High|Medium|Low" per feature/risk
2. Map confidence → CSS accent color and bar width (High=85%, Medium=55%, Low=30%)
3. Map complexity → badge variant
4. Animate bar width on mount with a CSS transition for the "filling up" reveal effect
5. On hover, expand card to show technical_approach or mitigation text
