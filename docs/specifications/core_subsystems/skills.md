# FixFlow AI - Core Subsystems & Skills Manual

This document details the design principles, operational guidelines, and code mappings for the five core engineering subsystems ("Skills") injected into the **FixFlow AI** codebase.

## ⚙️ Core Subsystem Catalog

### 1. Enterprise Semantic Brief Parsing & Schema Enforcement
*   **Purpose**: Processes highly chaotic, unstructured client inputs (text briefs, PDFs, chats) and maps them into deterministic JSON structures for proposal pipelines.
*   **Key Design Patterns**:
    *   **Strict Zod Guardrail**: Incoming JSON inputs are parsed using strict schema validation (`BriefOutputSchema`) which rejects unknown properties or malformed types.
    *   **Native Gemini Schema Injection**: Restricts Gemini's model output to a valid structured format utilizing native JSON schema constraints (`responseJsonSchema`).
    *   **Fallback Heuristics**: If schema parsing fails or throws an exception, the system automatically routes the payload through a sanitization function (`sanitizeAndPatchBrief`) that fills in missing properties with default safe strings or arrays, ensuring zero app crashes.
*   **Code Implementation**: [brief_parser.py](file:///c:/Users/suvam/Desktop/VS%20code/Projects/FixFlowAI/ai-service/app/features/brief_parser.py)

### 2. Deterministic Multi-Agent Orchestration (The Confidence Grid)
*   **Purpose**: Validates generated proposals against the original source brief using parallel persona workers, avoiding raw non-deterministic LLM evaluation loops.
*   **Key Design Patterns**:
    *   **Persona Isolation**: Runs parallel Gemini API requests for two distinct agent personas:
        *   *Auditor Agent*: Evaluates deliverables and flags budget alignment.
        *   *Feasibility Agent*: Checks technological feasibility and validates the realistic nature of timelines.
    *   **Mathematical Consensus**: Computes the mean of the scores from both agent evaluations to generate a 0-100 Confidence Index.
    *   **Idempotency & Resilience**: Treats evaluation results as immutable states that are logged and tracked in the database rather than running as transient memory.
*   **Code Implementation**: [confidence_grid.py](file:///c:/Users/suvam/Desktop/VS%20code/Projects/FixFlowAI/ai-service/app/features/confidence_grid.py)

### 3. Secure Milestone Mechanics & Versioning
*   **Purpose**: Manages the secure, transaction-safe lifecycle of milestone payments, deposits, and client-freelancer escrow releases.
*   **Key Design Patterns**:
    *   **Finite State Machine (FSM)**: Restricts milestone tracking to valid state transitions (`[Draft, Pending_Deposit, Active, In_Review, Revision_Requested, Approved, Funds_Released, Dispute]`).
    *   **Cryptographic Audit Trails**: Each state change generates a SHA-256 block-like hash chained to the `previousHash`, recording the timestamp, triggering user ID, role, and the state difference.
    *   **Optimistic Concurrency Control**: Uses an integer `version` field on the milestone records. If two operations attempt to update the state concurrently, the database rejects the second one because of a version mismatch, preventing double-payment releases.
*   **Code Implementation**: [escrowStateMachine.ts](file:///c:/Users/suvam/Desktop/VS%20code/Projects/FixFlowAI/backend/src/skills/escrowStateMachine.ts)

### 4. Cloud Infrastructure Scale & Pipeline Optimization
*   **Purpose**: Provides high-throughput real-time collaboration between agency and client dashboards without stalling the Node.js event loop.
*   **Key Design Patterns**:
    *   **WebSocket Stream Multiplexing**: Rooms are allocated per proposal. WS frames route subscribing clients and broadcast mutations.
    *   **Causal Vector Clocks**: Clients and servers track changes using vector clock maps (`Record<string, number>`) to trace logical edits.
    *   **Last-Write-Wins (LWW) Fallback**: For concurrent updates on identical fields, client timestamps act as the final conflict resolution tie-breaker.
*   **Code Implementation**:
    *   *Backend Service*: [syncServer.ts](file:///c:/Users/suvam/Desktop/VS%20code/Projects/FixFlowAI/backend/src/skills/syncServer.ts)
    *   *Frontend Coordinator*: [optimisticSync.ts](file:///c:/Users/suvam/Desktop/VS%20code/Projects/FixFlowAI/frontend/src/skills/optimisticSync.ts)

### 5. Pinpoint Self-Correction & Root-Cause Diagnostics
*   **Purpose**: Automates error correction when LLM structured outputs fall below quality benchmarks.
*   **Key Design Patterns**:
    *   **Self-Correction Loop**: If the Confidence Index generated by the *Confidence Grid* falls below `75`, the system triggers an autonomous optimization routine.
    *   **GAP Feedback Prompting**: The system extracts the explicit issues list compiled by the Auditor and Feasibility agents and feeds them back into a specialized optimization prompt alongside the original brief and proposal.
    *   **Automatic Proposal Reconciliation**: The optimization agent regenerates the proposal correcting the flagged issues, saving round-trips and manual editing time.
*   **Code Implementation**: [confidence_grid.py](file:///c:/Users/suvam/Desktop/VS%20code/Projects/FixFlowAI/ai-service/app/features/confidence_grid.py) (see `process_confidence_grid` function)

## 🧩 Extra Problem-Resolution Modules

To bridge the gap between strategic UVPs and actual code, five additional modules and MFA integration hooks were implemented:

### 1. Transparent Earnings Engine (`earningsCalculator.js`)
*   **Purpose**: Eliminates freelancer fee anxiety by pre-calculating exact payouts, platform cuts, taxes, and client checkout premiums.
*   **Design**: 
    *   Tiered Platform Commissions: `FREE` (10%), `SOLO` (5%), `PRO` (3%), `AGENCY` (2%).
    *   Payment Gateway Fees: Razorpay standard (2% of transaction amount + flat ₹3).
    *   TDS Withholding: Configurable rules based on location (e.g., 1% TDS for India `'IN'`).
    *   Client Premium: 1.5% checkout processing fee.
*   **Location**: [earningsCalculator.js](file:///c:/Users/suvam/Desktop/VS%20code/Projects/FixFlowAI/backend/src/skills/earningsCalculator.js)

### 2. Multi-Dimensional Reputation Engine (`reputationCalculator.js`)
*   **Purpose**: Creates game-proof trust scores by transforming raw transactional escrow history into verified performance indicators.
*   **Design**:
    *   On-Time Delivery Rate: Percentage of milestones completed before or on the due date.
    *   Revision Efficiency Score: Higher scores for fewer revision requests (`Math.max(0, 100 - (avgRevisions * 25))`).
    *   Dispute-Free Rate: Percentage of dispute-free milestones.
    *   Repeat Client Rate: Ratio of repeat contracts to reward developer-client retention.
    *   SBT Schema Builder: Synthesizes attributes into ERC-721 JSON for Polygon minting.
*   **Location**: [reputationCalculator.js](file:///c:/Users/suvam/Desktop/VS%20code/Projects/FixFlowAI/backend/src/skills/reputationCalculator.js)

### 3. Client Behavior Scoring & Risk Profiler (`clientScoring.js`)
*   **Purpose**: Protects freelancers against late payers, scope creep, and hostile clients.
*   **Design**:
    *   Scope Stability Score: Derived from revision requests relative to milestones (`max(0, 100 - (edits / milestones * 100))`).
    *   Payment Speed Score: Continuous inverse mapping of approval time in hours (faster approvals yield higher scores).
    *   Risk Classifier: Flags `SCOPE_CREEP_RISK` (stability < 60), `LATE_PAYER_RISK` (speed < 55), `HIGH_DISPUTE_RISK` (disputes > 15%), and awards `PREMIUM_CLIENT` badges.
*   **Location**: [clientScoring.js](file:///c:/Users/suvam/Desktop/VS%20code/Projects/FixFlowAI/backend/src/skills/clientScoring.js)

### 4. Dynamic Interview Vetting Generator (`interviewGenerator.ts`)
*   **Purpose**: Minimizes client screening fatigue and shortens vetting cycles.
*   **Design**:
    *   Custom Prompts: Combines the project brief, candidate's GitHub scan summary, and missing skills gap list.
    *   Gemini Integration: Uses `gemini-2.5-pro` with structured JSON schema output to produce 3-5 technical questions, rationales, and expected keywords.
    *   Self-Healing Fallbacks: Automatically outputs tailored fallback questions if the API key is invalid or requests fail.
*   **Location**: [interview.py](file:///c:/Users/suvam/Desktop/VS%20code/Projects/FixFlowAI/ai-service/app/features/interview.py)

### 5. Contextual Contract Extensions (`contextExtensions.ts`)
*   **Purpose**: Promotes freelancer-client retention by suggesting next-phase milestones based on completed work.
*   **Design**:
    *   Strategic Prompts: Analyzes completed deliverables and chat discussion summaries.
    *   Milestones Proposal: Recommends 1-3 logical next-phase milestones with descriptions, durations, and budget estimates.
    *   Automated Drafts: Generates polite, copy-ready proposal messages.
*   **Location**: [extensions.py](file:///c:/Users/suvam/Desktop/VS%20code/Projects/FixFlowAI/ai-service/app/features/extensions.py)

### 6. MFA Payout Releases (FSM Security Hook)
*   **Purpose**: Hardens payment releasing operations against session hijacking.
*   **Design**:
    *   Custom Exception: Throws `MFARequiredError` if transition to `Approved` or `Funds_Released` is requested without an authentication token callback.
    *   Audit Log Stamp: Appends `[MFA Verified]` to the cryptographically linked ledger block metadata.
*   **Location**: [escrowStateMachine.ts](file:///c:/Users/suvam/Desktop/VS%20code/Projects/FixFlowAI/backend/src/skills/escrowStateMachine.ts#L129)
